# Pairing Moonlight WiiU with Sunshine

The Batocera Wii U GamePad runtime does **not** run Sunshine permanently.

Sunshine NoCursor starts automatically only after a Wii U game has been launched and Cemu has
been detected. This is intentional: outside a Wii U session, no GamePad stream is needed.

## First pairing

1. Install the Batocera package and install **Moonlight WiiU** on the Android phone/tablet.
2. Make sure the Android device and Batocera machine are on the same local network.
3. Launch a Wii U game from EmulationStation.
4. Wait until Cemu has started. The Wii U GamePad runtime will automatically:
   - create the virtual `WIIU-GAMEPAD` output;
   - create the GamePad audio sink;
   - start Sunshine NoCursor.
5. Open Moonlight WiiU on Android.
6. Select the Batocera host.

If automatic host discovery does not find the machine, use the **+** button in Moonlight and
enter the Batocera machine's local IPv4 address only, for example:

```text
192.168.1.42
```

Do not enter `https://` or port `:47990` in Moonlight's manual-host field.

7. Moonlight displays a four-digit PIN.
8. On the Android device or another browser on the LAN, open Sunshine's Web UI:

```text
https://<BATOCERA-IP>:47990
```

Example:

```text
https://192.168.1.42:47990
```

9. Accept the browser warning for Sunshine's self-signed local HTTPS certificate if required.

### First Sunshine Web UI login on a fresh installation

The release package does **not** ship a preset Sunshine username/password and does not include a
pre-existing `sunshine_state.json`.

On the first Sunshine Web UI access of a fresh installation, Sunshine asks the user to create a
username and password for the Web UI. No terminal command is normally required.

Create those credentials and keep them somewhere safe. They protect access to Sunshine's
configuration and pairing interface.

10. Create the Sunshine Web UI username/password if this is the first launch, or sign in with the
    existing credentials on an upgraded installation.
11. Open **PIN Pairing**, select the waiting client if Sunshine lists one, enter the PIN shown by
    Moonlight, and confirm.

After pairing, Moonlight remembers the host. Normal Wii U sessions no longer require repeating
this procedure.

## Forgotten Sunshine Web UI credentials

The Sunshine Web UI username/password is separate from Moonlight's four-digit pairing PIN.

If the Web UI credentials are forgotten, close the Wii U game first so Sunshine stops, then reset
them from a Batocera terminal:

```bash
/userdata/system/wiiu-gamepad/sunshine/Sunshine-NoCursor.AppImage \
  --creds NEW_USERNAME NEW_PASSWORD
```

Replace `NEW_USERNAME` and `NEW_PASSWORD` with the desired credentials, then launch a Wii U game
again and sign in to the Web UI with the new account.

This command changes the Sunshine Web UI credentials; it is not the Moonlight pairing PIN.

## Important: Sunshine must be running

If Moonlight shows:

> Searching for PCs on your local network...

while no Wii U game is running, this is expected. Sunshine is intentionally stopped outside a
Wii U session.

Launch the Wii U game first, then open/connect Moonlight.

## Sunshine Web UI / CSRF

The installer automatically adds the Batocera machine's current local IPv4 Sunshine Web UI origins
to `csrf_allowed_origins` and enables LAN Web UI access.

This avoids the Sunshine **CSRF Protection Error** encountered when pairing from a phone browser.
The configuration is regenerated by the runtime when its machine configuration is refreshed, so a
DHCP address change does not require hard-coding a specific IP in the release package.

## If the host is still not found

Verify that the Wii U game is currently running, then try manual IP entry in Moonlight.

On Batocera, the machine's IPv4 address is displayed in the system information screen. It can also
be inspected from a terminal with:

```bash
ip -4 -o addr show scope global
```

If Sunshine's Web UI opens at `https://<BATOCERA-IP>:47990` but automatic Moonlight discovery does
not work, manual IP entry is sufficient; automatic discovery is not required for streaming or touch
input.
